# AI Debate History

과거 토론 이력을 조회합니다.

## Instructions

1. `.debates/` 디렉토리에서 토론 목록을 조회합니다.

```bash
ls -la "{{SKILL_DIR}}/../../.debates/" 2>/dev/null || echo "아직 토론 기록이 없습니다."
```

2. 각 토론의 `debate.json`을 읽어 요약을 표시합니다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📚 AI 토론 이력
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. [날짜] "주제" — 참여자 N명 — ✅ 합의 / ❌ 미합의
2. [날짜] "주제" — 참여자 N명 — ✅ 합의 / ❌ 미합의
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

3. 사용자가 특정 토론을 선택하면 `output.md`를 읽어 전문을 표시합니다.

4. `output.md`가 없으면 `debate.json`의 메타데이터를 표시합니다.
